# Content checklist

Update these before publishing:

- Your name + role: `src/config/site.ts`
- Company email + personal email: `src/config/site.ts`
- Phones (call + WhatsApp): `src/config/site.ts`
- Social links: `src/config/site.ts`
- Headshot: `public/brand/headshot.jpg` (source file in `docs/source-assets/Image/My Photo.jpg`)
- Company logo: `public/brand/logo.png` (source file in `docs/source-assets/Image/sinshine Tech solution logo.png`)
- Domain for SEO + sitemap: set `SITE_URL` (env var) and update `site.seo.siteUrl` in `src/config/site.ts`
- Projects: `src/content/projects/*.md`
- Case studies: `src/content/case-studies/*.md`
- Insights/blog posts: `src/content/insights/*.md`
- OpenGraph image: `public/og.svg`
