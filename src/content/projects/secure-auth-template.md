## What this is

Authentication is easy to get wrong, so I like building small starter templates to practice the basics:
sign in, sign out, protected routes, and a minimal admin dashboard.

## What I focused on

- Clean route protection (no “secret pages” by accident)
- Simple admin UI layout
- Reasonable defaults (validation, error states, clear messages)
