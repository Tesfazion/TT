## What this is

I like building small “glue” systems that save time. This project is a collection of simple workflow ideas:
someone fills a form → the right person gets notified → we keep a basic log → we can see a quick report later.

## What it covers

- A clean lead / request form with a few structured questions
- Auto‑routing based on the service type (or urgency)
- Notifications to WhatsApp / Telegram / email
- A lightweight log (spreadsheet or a small database) + simple dashboard

## What I learned

- Reliability matters more than fancy features
- Better form questions = fewer back‑and‑forth messages
- “Good enough” reporting is still very useful day‑to‑day
